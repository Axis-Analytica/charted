# Working on charted (for coding agents)

Read [docs/HANDOFF.md](docs/HANDOFF.md) first: the architecture, the state, and the
traps. [CONTRIBUTING.md](CONTRIBUTING.md) has the layout and conventions; this file has
the rules agents most often break.

## Running things

- **New shells:** run `. bin/env` before any cargo or pnpm command.
- **Use `bin/heavy` for anything heavy.** Every `cargo build/test/clippy/check/run`,
  Playwright and Vitest run goes through it: `bin/heavy cargo test -p charted-core`. A
  bare cargo run can get the user's terminal killed by systemd-oomd on small machines.
- **Full suite:** `bin/test` (it wraps itself in `bin/heavy`). Playwright needs
  `CHROMIUM_PATH=$(command -v chromium)`.
- **Killing processes:** never `pkill -f` or `pgrep -f` with a pattern that also appears
  in your own command line; it kills your shell. Use pid files or `fuser -k PORT/tcp`.

## Editing

- **Never run prettier (or any formatter) on `ui/`**: it rewraps whole files. Rust uses
  `cargo fmt --all`.
- **Generated files, regenerated by commands:**
  - `ui/src/bridge/generated/*`: from Rust types by `bin/heavy cargo test -p <crate>`.
    Check for name clashes: two crates exporting the same type name overwrite each
    other's file; use `#[ts(rename = …)]`.
  - `crates/agent/src/catalog.json`: from the UI's visual registry by
    `CHARTED_UPDATE_CATALOG=1 bin/heavy pnpm -C ui exec vitest run catalog`.
  - `docs/dax-support.md`: by `CHARTED_UPDATE_DOCS=1 bin/heavy cargo test -p charted-dax`.
  - `ui/src/dax/pkg` (untracked): by `bin/wasm`.
- **i18n catalogs (`i18n/da.json`, `i18n/ar.json`):** append new keys at the end and
  never re-sort or rewrite the files.
- **Model and report changes** go through `Change` and `Session::commit`, never direct
  mutation, so undo keeps working.
- **End-to-end specs share one sample project.** Undo what a spec changes. Don't assume
  page names: earlier specs rename and add pages.

## Asking first

Pushing, tagging a release, and publishing to the AUR or omarchy-pkgs need the
maintainer's explicit go-ahead.
