# Milestone 4 checkpoint: interactivity

Run `bin/checkpoint m4`. It builds charted, creates a fresh sample at
`~/Work/charted-checkpoints/Harbor & Pine`, runs the scripted flow in Chromium
(screenshots in `~/Work/charted-checkpoints/m4/`), opens the project the tests built in
the real window (`m4-window-interactivity.png` with a matrix row chosen,
`m4-window-visuals.png`), then opens the app with the fresh sample.

1. **Build a page.** Add a *Card* (Sales → Total Sales), a *Clustered column chart*
   (Product → Category, Total Sales), a *Line chart* (Date → YearMonth, Total Sales), a
   *Matrix* (drag Category then Subcategory into *Rows*, Year into *Columns*, Total
   Sales into *Values*) and a *Slicer* (Store → Region). The matrix starts collapsed to
   categories, with a total for each year, a *Total* column and a *Total* row.
2. **Click a column.** The card, the line and the matrix filter to that category, and a
   small filter badge on each says a selection elsewhere is filtering it; the other
   columns dim. **Ctrl-click** another column to add it; click it again to take it
   out. Click empty canvas (or press Escape) to clear.
3. **Highlight.** Click *Camping* in the matrix (the label, not the arrow). Column and
   bar charts don't filter, they *highlight*: each bar keeps its full height, faded,
   with the part that belongs to the selection drawn solid (here only Camping's own
   bar). Select a region in the slicer first and click a matrix row again to see every
   bar split. Hovering a bar shows both numbers.
4. **Slicers.** Tick *North America* in the slicer: everything else on the page filters.
   Click another value to switch; Ctrl-click (or *Multi-select without Ctrl* in Format)
   to pick several; the eraser in its header clears it. The choice is saved with the
   report and undoable. In *Format → Slicer settings*, *Style* switches to a dropdown,
   *Between* (a date or number range with a slider; try Date) or *Relative date* ("last
   3 months"). Slicers filter each other too.
5. **Edit interactions.** Select the slicer, then press *Edit interactions* (the pointer
   icon in the toolbar). Every other visual shows how the slicer affects it: *Filter*,
   *Highlight* (charts that can) or *None*. Set the card to *None*: it shows the total
   again while the rest stay sliced. Do the same with a chart selected as the source.
   Press the toolbar button again to finish.
6. **Expand the matrix.** The arrow beside a category expands it to its subcategories
   (the category row becomes its subtotal); the visual's *⋯* menu has *Expand all* and
   *Collapse all*. Subtotals are computed for each level (a distinct count or a ratio
   is right at every level, not summed).
7. **More visuals.** The gallery adds stacked column and bar, pie and donut, scatter
   (bubble with *Size*), matrix, slicer, text box (double-click to type), image (from a
   file; stored in the report) and shape. Change a visual's type from the gallery and
   its fields carry over.
8. **Focus mode, show as a table, export.** Hover a visual: the focus icon shows it on
   its own; *Show as a table* (in focus mode, or the *⋯* menu) puts its data below it.
   *⋯ → Export data* writes the data it shows (with any cross-filter) as CSV.
9. **Themes.** The palette button in the toolbar: *Omarchy (follows the desktop)* is the
   default, *Classic* (Power BI's default palette), *Daylight* and *Nightfall*
   (colour-blind-checked palettes), or *Browse for themes…* to import a Power BI theme
   JSON (its `dataColors`, `background`, `foreground` and `tableAccent` are used; the
   whole file is kept). Choose Omarchy again and switch your desktop theme
   (the Omarchy menu, or `omarchy-theme-set <name>`): the report follows it live.

Everything is undoable except the selection itself and the matrix's expansion, which
are view state (as in Power BI Desktop).
