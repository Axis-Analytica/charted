# M9 demo: a deeper agent

Open the sample (*Explore the sample*) and the Agent pane (Ctrl+I). The scripted
versions are in `ui/e2e/m7agent.spec.ts` (with a stand-in agent) and `bin/eval` (with a
real one).

## It looks at the page

Turn on *Let the agent see data* (the database button in the pane's header), then ask:

> Build a page with sales by month as a line and sales by category as a donut, then
> check it looks right.

After building, the agent calls `screenshot_page`: charted draws the page off screen and
sends the agent a picture, so it can see overlaps, cramped charts or unreadable labels.
The step reads *Looked at page "…"*. Without data access the step is refused, because
a picture shows the numbers.

## Project instructions

The notebook button in the pane's header opens the project's instructions, kept in
`agent.md` in the project folder (with the project, so they travel with it):

```
- Use the Date table for anything over time
- Titles in sentence case
- Money in thousands, no decimals
```

The agent gets them with every request. Ask it to remember a rule ("remember that our
fiscal year starts in July") and it asks before adding a line.

## Report-wide formatting

> Make every visual title sentence case at 14 px.

One step, *Formatted 12 visuals*, through `format_visuals`. Acronyms such as YoY stay
as they are. Objects a visual type doesn't have are skipped.

## Without the window

```
charted mcp --project ~/Documents/charted/Sales
```

is an MCP server over stdio with the same tools, for agents run from scripts or CI. Add
it to the agent's MCP config. Each change is saved at once. While it runs, the app
can't open the project. `--data` allows rows and values; `--allow-deletes` allows
deleting pages, tables and things in use. Screenshots and Power Query drafts need the
window.

## Evaluations

```
bin/eval                                   # all cases, Claude Code with sonnet
CHARTED_EVAL=build,yoy CHARTED_EVAL_MODEL=haiku bin/eval
```

Five requests on a fresh sample, each scored by checks on the model it leaves: build a
page, a year-on-year measure, tidy a messy page, a calculation group, and report-wide
title formatting. Results append to `target/evals.jsonl`. They cost money, so they run
only when asked. First run (2026-10-31, sonnet): 5/5, 7–12 s and about $0.04 each.
