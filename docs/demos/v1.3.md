# v1.3 demo: report building

Open the sample (*Explore the sample*) in the app (`bin/dev`) or in a browser against the
dev server. The scripted version of each step is in `ui/e2e/v13.spec.ts`
(`cd ui && npx playwright test e2e/v13.spec.ts`; `CHARTED_SHOTS=<dir>` saves screenshots).

1. **Selection pane.** Add a page with a card (Total Sales), a text box and a shape. The
   layers button in the report toolbar (*Selection pane*) lists them top layer first.
   Click a name to select it on the canvas (Ctrl or Shift adds); click on the canvas and
   the pane follows. The eye hides a visual: it leaves the canvas but stays in the pane,
   where it can still be selected and formatted. Drag a layer, or focus it and press
   Alt+↑/↓, to change the layer order; the order is also the tab order (Power BI's
   `tabOrder` on export). *Show all* / *Hide all* at the top.
2. **Format several visuals.** Select two text boxes (Ctrl+click). The Format tab says
   *Formatting 2 visuals* and shows the options they share; different values show as
   *Mixed* (a text size, an indeterminate checkbox). Tick *Bold*: both change, and one
   `Ctrl+Z` undoes both. A card and a chart together share only Title and Background.
3. **Format painter.** Select a styled text box and press the paintbrush (*Format
   painter*); click another text box: it takes the look (size, colour, bold) and keeps
   its own words. Double-click the paintbrush to keep it on for several visuals; Esc
   turns it off. `Ctrl+Alt+C` copies the selected visual's look and `Ctrl+Alt+V` pastes it
   onto every selected visual. Fields, titles' text and button actions are never copied.
4. **Copy and paste visuals.** Select visuals, `Ctrl+C`, `Ctrl+V`: the copies land on top,
   offset, and selected. `Ctrl+X` cuts. Switch page and `Ctrl+V`: they land where they
   were. Close the project, open another (or a new one) and paste: fields the model
   doesn't have (by table and field name) are left out, with a toast saying how many.
   The clipboard holds JSON marked `application/x-charted-visuals`.
5. **Sync slicers.** Page A: a card and a Store → Region slicer; page B: a card. Select
   the slicer, open *Sync slicers pane* (the circling arrows). Tick *Sync* for page B:
   a hidden copy goes there. Pick North America on page A, go to page B: its card is
   filtered too, with no slicer on the page. Back on A, tick *Visible* for B: the copy
   shows, with North America chosen. Clear it on B and both pages show all regions; one
   `Ctrl+Z` brings the choice back on both. *Advanced options* shows the group name
   (Region): slicers with the same group share one choice.
6. **Buttons and a page navigator.** Add a page *Details*, then on another page a
   *Button*: in Format → Button pick the *Page navigation* icon and type a text; in
   *Action* choose *Details* as the destination. A click selects the button; Ctrl+click
   follows it (as in Power BI Desktop). Add a *Back* button on Details and Ctrl+click it.
   Add a *Page navigator*: a button per page, the current one highlighted. On *Details*,
   with nothing selected, Format → *Hide page*: it drops out of the navigator. The
   book icon (*Reading view*) hides the panes and the hidden pages' tabs; there a plain
   click on a button or navigator acts. *Edit report* returns. Buttons can also show a
   bookmark or drill through (with a data point selected on the page).
7. **Export to PDF.** *File → Export to PDF…* asks where to save, shows the pages it is
   preparing, and writes one PDF page per report page not hidden, at the page's size
   (1280 × 720 pages give 960 × 540 pt sheets), with the current filters and slicers.
   From the command line:

   ```sh
   cargo build -p charted --features custom-protocol   # after `cd ui && pnpm build`
   target/debug/charted open "Documents/charted/Harbor & Pine" --export-pdf out.pdf
   pdfinfo out.pdf        # Pages: one per page not hidden; Page size: 960 x 540 pts
   pdftoppm -png -r 50 -f 1 -l 1 out.pdf page   # look at the first page
   ```

   The window opens, the UI lays the pages out, waits until every visual has its data,
   and WebKitGTK prints to the file (no dialog); the command prints the path and exits 0
   (1 on failure, or after `CHARTED_EXPORT_TIMEOUT_S`, default 300 s). A debug build
   without `custom-protocol` loads the UI from the Vite dev server on port 1420 instead.
   In a browser, *Export to PDF…* shows the same layout with a *Print…* button.

Not in this release: bookmarks don't yet capture which visuals are hidden (Power BI's
*Display* option); a PDF's sheets all take the first page's size (pages of other sizes are
scaled to fit); ticking *Visible* in the sync pane also syncs (Power BI also allows a
visible copy that isn't synced), and its field/filter-change options are always on.
