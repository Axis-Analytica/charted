# M8 demo: reshape charted itself

Open the sample (*Explore the sample*). The scripted version is `ui/e2e/m8layout.spec.ts`
(`CHARTED_SHOTS=<dir>` saves screenshots).

## Profiles

The **Layout** menu in the top bar names the active profile. Each user has several
profiles, kept per user (`<state dir>/workspace.json`), never per project. Three are
built in:

- **Standard:** the panes on the right, one view.
- **Report + model:** the model diagram beside the report.
- **Two report pages:** two reports side by side. Each keeps its own page; add a page in
  the right-hand one, and the left stays where it was. The panes act on the report you
  used last.

*New profile…* copies the active one. *Rename* and *Delete* do what they say. *Reset*
puts a built-in profile back as it ships.

## Panes

- **Docking.** Right-click a pane's header (Fields, Filters, Visualizations, Bookmarks,
  Selection, Sync slicers, Agent), or press Shift+F10 on it, and choose *Dock on the
  left*, *Dock on the right*, *Float* or *Hide pane*. A docked pane resizes from its
  inner edge.
- **Floating.** A floating pane moves by its header and resizes from its corner. It sits
  over the report.
- **Narrow windows.** Docked panes share one tabbed column, as before. The Agent pane
  stays in view, because it holds a conversation.

## The side-by-side view

*Layout → The model beside it* (or a second report, the data, or Transform data) puts a
second view beside the one picked in the rail. Drag the divider to resize. *One view*
goes back.

## Buttons

- **Hiding.** Right-click a report toolbar button and choose *Hide … from the toolbar*.
- **Still reachable.** A hidden button stays in the command palette (Ctrl+K), along with
  every toolbar command.
- **Bringing back.** *Layout → Hidden buttons (n)…* lists them, with *Show* for each and
  *Show all*.

## Undo

Layout changes have their own undo: *Layout → Undo layout change* (or *Undo layout
change* in Ctrl+K). It's separate from the project's undo, because a layout isn't part of
the project.

## The agent does it too

Ask the Agent pane, for example: *"Float the fields pane, put the model beside the
report, and hide the buttons I've never pressed."*

- **Its layout tools:** `describe_workspace`, `set_pane`, `split_view`, `list_commands`,
  `hide_commands` and `profile`.
- **Usage counts.** `list_commands` shows how often you've clicked each button on this
  machine. The count is kept locally and sent only with your requests.
- **Asking first.** Hiding buttons and deleting a profile ask *Allow / Skip* first.
- **Undo.** The whole request undoes in one *Undo layout change*.
