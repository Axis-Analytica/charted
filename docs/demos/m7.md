# M7 demo: the agent inside charted

Open the sample (*Explore the sample*) in the app (`bin/dev`). Claude Code or Codex must
be installed and signed in. The scripted version, with a stand-in agent, is
`ui/e2e/m7agent.spec.ts`
(`cd ui && CHROMIUM_PATH=$(command -v chromium) npx playwright test e2e/m7agent.spec.ts`;
`CHARTED_SHOTS=<dir>` saves screenshots). The checkpoint with Claude Code itself is
`bin/heavy cargo test -p charted-cli --test agent -- --ignored --nocapture`.

## Build a page

1. **Open the pane.** Press **Ctrl+I**, or use the sparkles button at the right of the
   report toolbar. The Agent pane opens on the right. Its header shows the agent and
   model: Omarchy's default agent, with its own default model. The menu also offers the
   other installed agents and Claude's opus, sonnet and haiku.
2. **Ask.** Type *Build a page with sales by month as a line, sales by category as a
   donut and a region slicer.* and press Enter. The chip above the box shows what goes
   with the request: the page you're on, plus any selected visuals. Its × leaves that
   out.
3. **Consent, once per agent.** The first request asks before anything leaves the
   machine. It lists what the provider sees:
   - names, types and DAX;
   - the report's pages and visuals;
   - the totals the agent checks, with their labels, up to 50 rows.

   Rows and value lists need *Let the agent see data*. The agent can't read files or run
   commands. *Agree and send*.
4. **Watch it work.**
   - Each step appears as one line in the pane as it lands: *Added page "Sales
     Overview"*, *Added line chart "Sales by month"*, and so on.
   - The canvas moves to the new page. The visuals appear one by one, each outlined
     briefly, and are then arranged.
   - The agent checks its numbers with `query_visual`, then sums up in a sentence or
     two.
   - The cost shows under the request (about $0.07 with sonnet).
   - Clicking a step selects what it made. The chevron shows the fields or DAX.
5. **Undo it in one step.** The toolbar's Undo now reads *Undo Agent: Build a page…*.
   It, or the request's *Undo this request*, takes the whole page back.

## Follow-ups, edits meanwhile, and Stop

- **Follow-ups.** Ask *Add a measure for average order value and show it as a card on
  that page.* The agent remembers the conversation, because the session is resumed.
  - It writes the measure. The DAX is checked first; a measure that doesn't check isn't
    saved, and the agent is told why.
  - It adds the card and re-arranges the page.
  - The conversation is kept with the project. *New chat* starts afresh.
- **Edit while it works.** Your changes interleave as their own undo steps. The request
  can then no longer undo as one: *Undo this request* is disabled with a note, and
  Ctrl+Z goes step by step. If you move to another page during a request, the canvas
  stops following the agent.
- **Stop.** *Stop* ends the agent and stops its tools from answering. What it did so far
  stays, and still undoes as one step.

## What it may do and see

- **Everything in the model and report.** Pages, visuals and their formatting, filters
  (report, page, visual), themes, bookmarks, measures, calculated columns and tables,
  column properties, relationships, hierarchies, roles, calculation groups, and field
  and numeric parameters.
- **Names resolve, with suggestions.** Fields are named `'Table'[Column]`, `[Measure]`
  or `SUM('T'[C])`. A wrong name gets the nearest real ones back.
- **Big deletes ask first.** Removing a page, table, relationship or role, or a measure
  or column that something uses, shows *The agent asks: Delete …?* with *Allow* and
  *Skip*. *Skip* leaves it, and the agent carries on.
- **Data access.** The database button in the pane's header (*Let the agent see data*)
  is per project and off by default.
  - **Off:** the agent sees totals only. `query_visual` answers only for visuals that
    aggregate, and `distinct_values` and `sample_rows` are refused (shown as a red
    step).
  - **On:** those tools work.
- **Power Query drafts.** Ask *Sort the Store query by region*.
  - The agent drafts the step, checked against the columns it leaves.
  - A card offers *Apply* or *Discard*. Applying reloads that query's data and starts
    undo afresh, as Close & Apply does, so only the user can do it.

## Other agents

Agents that can't run inside the pane (OpenCode, Crush, Cursor and others) are listed
as *(in a terminal)*. The button becomes *Open in terminal*. It opens the agent through
`omarchy-agent-prompt`, in a folder whose MCP settings point at charted. Its steps still
show in the pane, and its changes undo together.
