# Milestone 0 checkpoint: the spine

Run `bin/checkpoint m0`. It builds charted, creates a fresh sample project at
`~/Work/charted-checkpoints/Harbor & Pine`, saves screenshots to
`~/Work/charted-checkpoints/m0/`, and opens the app with the sample.

1. **Your theme.** The window uses your current Omarchy colours and corner rounding.
   Press `?` for the keyboard shortcuts and `Ctrl+K` for the command palette.
2. **The sample.** The Tables sidebar lists Sales, Date, Product, Customer, Store and
   Targets with row counts. Select a table to preview its first 200 rows; amounts use
   the model's currency format. Expand a table (→ or the chevron) to see its measures
   and columns. Click **Load query** to see the SQL that loaded it.
3. **Live theme.** In a terminal, switch theme (`omarchy theme set <name>`, or use the
   Omarchy menu). charted recolours within a second, without restarting.
4. **Live rounding.** `hyprctl keyword decoration:rounding 10` rounds buttons and panels;
   `hyprctl keyword decoration:rounding 0` restores sharp corners.
5. **Language.** `echo da > ~/.config/omarchy/language` switches the UI to Danish
   (numbers use `,` decimals); `echo ar > ~/.config/omarchy/language` mirrors the layout
   right to left. Remove the file (or write `en`) to return to English.
6. **Edit, undo, save.** Select Customer, press `F2`, rename it to `Clients`, Enter. The
   accent dot shows unsaved changes. `Ctrl+Z` / `Ctrl+Shift+Z` undo and redo. `Ctrl+S`
   saves; in the project folder, `git init && git add -A && git commit -m base` before
   renaming shows the change as a one-line diff in `model.ossie.yaml`.
7. **Quit safely.** Make another change and press `Q`: charted asks before discarding.
8. **For agents.** From a terminal:
   `target/debug/charted check "$HOME/Work/charted-checkpoints/Harbor & Pine"` and
   `target/debug/charted query "$HOME/Work/charted-checkpoints/Harbor & Pine" "select Channel, round(sum(Amount)) from sales group by 1" --json`.
9. **Component kit.** `Ctrl+Alt+K` shows every UI component and design token in the live
   theme.
