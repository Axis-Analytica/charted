# Milestone 2 checkpoint: the first report

Run `bin/checkpoint m2`. It builds charted, creates a fresh sample at
`~/Work/charted-checkpoints/Harbor & Pine`, runs the scripted flow in Chromium (screenshots
in `~/Work/charted-checkpoints/m2/`, plus the project it built, opened once in the real
window for `m2-window-built.png`), and opens the app with the fresh sample.

The project opens in the **Report view** (Ctrl+1; the Data view is Ctrl+2). On the right:
Filters, Visualizations (types, Build, Format) and Fields; at the bottom, page tabs.

1. **Name the page.** Double-click the "Page 1" tab, type `Overview`, Enter.
2. **A measure in DAX.** Press `Ctrl+M` (or the `+` next to Sales in Fields). Type
   `Margin % = DIVIDE ( [Total Sales] - [Total Cost], [Total Sales] )`. Mistakes are
   flagged as you type (try deleting a `]`), with the position. Enter creates it; pick
   *Percentage* in the formula bar's format list. ✨ *Quick measure* writes DAX for
   common calculations.
3. **Cards.** Move the pointer to the top left of the page, click the *Card* type, tick
   *Total Sales* in Fields: the card appears under the pointer showing `$49.3M`. Add a
   second card with *Margin %*.
4. **Column chart.** Click an empty spot, choose *Clustered column chart*, tick
   Product → *Category* and *Total Sales*: categories ranked by value, coloured with
   your theme's accent. Or drag fields straight onto the canvas or into the wells.
5. **Line chart.** *Line chart* with Date → *YearMonth* and *Total Sales*.
6. **Table.** *Table* with Store → *Region*, *Total Sales* and *Margin %*, with a total
   row. Click a column header to sort it.
7. **Page filter.** Drag Date → *Year* onto *Filters on this page*, open the card, tick
   2025. Every visual updates; the card now shows 2025's sales.
8. **Arrange.** Shift-click (or drag a marquee around) the two cards, then *Align top*
   in the toolbar. Drag visuals: they snap to the grid and to each other's edges and
   centres. Arrows nudge by 1, Shift+arrows by 8, `Ctrl+D` duplicates, Delete removes.
   Every change is one undo step (`Ctrl+Z`).
9. **Format.** With a visual selected, the *Format* tab lists its options (title, legend,
   axes, data labels, colours…). With nothing selected it shows the page's settings.
10. **Save and reopen.** `Ctrl+S`, `Ctrl+W`, then open the project again from the
    welcome screen: the page is identical. `report/` holds one JSON file per page and
    per visual; `model.ossie.yaml` now has the measure with an `OSSIE_SQL_2026`
    translation next to the DAX.
11. **For agents.** Close the project in the app, then
    `target/debug/charted query "$HOME/Work/charted-checkpoints/Harbor & Pine" --visual "Total Sales by Category" --json`
    prints that visual's rows (`--show-sql` shows the SQL it runs).
