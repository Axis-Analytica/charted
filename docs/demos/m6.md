# Milestone 6 checkpoint: interop, polish, release (v1.0.0)

Run `bin/checkpoint m6`. It builds charted, makes a fresh sample, runs the scripted flows
in Chromium (screenshots in `~/Work/charted-checkpoints/m6/`), shows the Trends page in
the real window (`m6-window-trends.png`) and the release build serving its own UI
(`m6-window-release.png`, after `bin/build`), then opens the app with the sample.

To install charted as a package (it then appears in the launcher, Super+Space, and opens
`.charted`, `.chartedz` and `.pbip` files): `bin/install`. It asks for your password
once, for pacman.

1. **Launch from the launcher.** Super+Space, type *charted*. The window opens on the
   welcome screen in the Omarchy colours.
   **Start from scratch:** *New project…* (or `Ctrl+N`, or File → New project…) asks for
   a name and creates the project folder in Documents/charted (or a folder you choose).
   It opens on a blank page that says there's no data yet; *Get data* opens Transform
   data, where *New source* reads a file; Close & Apply, and its fields are ready.
2. **A Trends page with last year and year to date.** Open the sample, add a page
   *Trends*. `Ctrl+M` and type
   `Sales LY = CALCULATE ( [Total Sales], SAMEPERIODLASTYEAR ( 'Date'[Date] ) )`, Enter;
   again for `Sales YTD = TOTALYTD ( [Total Sales], 'Date'[Date] )`. A line chart of Date
   → YearMonth with Total Sales and Sales LY shows last year's line a year behind (empty
   for 2022); a table by Year with Total Sales and Sales YTD shows each December's YTD
   equal to the year's total. `TOTALYTD ( …, "6/30" )` gives a fiscal year to June,
   and DATEADD, PARALLELPERIOD, DATESMTD/QTD, PREVIOUS… and NEXT… work too.
   No date table? *Model view → New date table*: pick the years (read from your date
   columns) and the month the fiscal year starts; it's marked as the date table and
   related to the date columns you tick.
3. **Drill down and up.** A clustered column chart with Date → Year, Quarter and
   MonthName dragged into the X-axis shows the years. On its header: ↓ turns drill
   mode on, then a click on 2024 shows its quarters (and on a quarter, its months);
   ↑ goes back up; ⇊ shows the next level for every year; the fork expands all down one
   level ("2024 Q1"…). Right-click a column for *Drill down* / *Drill up* too.
4. **Drill through.** Add a page *Category detail* with a card of Total Sales; with
   nothing selected, drag Product → Category into *Drill through* in the Filters pane
   (*Keep all filters* is on). Back on Trends, right-click a bar of a chart by Category →
   *Drill through* → *Category detail*: the page opens filtered to that category, with
   a bar saying so and a back button.
5. **Bookmarks with the keyboard.** The bookmark button (top right of the report
   toolbar) opens *Bookmarks*. Add one (the years), drill the column chart into 2024, add
   another and rename it (F2). `Ctrl+Alt+←` and `Ctrl+Alt+→` step between them: the page,
   filters, slicers, sorts and drill state come back. In the list, ↑/↓ move, Enter shows,
   Alt+↑/↓ reorder, Delete removes.
6. **Import a Power BI project.** *File → Import Power BI project…* and choose
   `crates/core/tests/fixtures/Contoso/Contoso.pbip` (written the way Power BI Desktop
   writes one). It becomes a new project in Documents/charted, and the import report
   lists what didn't come across: the calculation group, the security role, the
   hierarchy, the automatic date table, the calculated Date table and the SQL Server
   query (both come in without data), the map and KPI visuals, and RANKX. The data files
   it names (`C:\Users\Analyst\…`) are found next to the project. The Overview page shows
   the card, column chart, table and slicer with the page filter (Camping, Footwear).
   From the command line: `charted import-pbip <file.pbip> --json`.
7. **Export → re-import with no differences.** *File → Export Power BI project…* writes
   TMDL and the report as PBIR (checked against Microsoft's schemas), with charted's
   queries and report state kept in annotations. Import that export: only RANKX is
   reported, and the model is identical (`crates/core/tests/pbimport.rs` checks the
   diff is empty and the report equal).
8. **Open a bundle.** *File → Save as bundle…* writes one `.chartedz` (the project and its
   data files, without the cache). Close the project; on the welcome screen *Open a
   bundle or Power BI project…* (or double-click it once installed) opens it as a new
   folder.

Also in M6: F6 / Shift+F6 move between the window's regions; a visual that fails to draw
says so in its own frame (with *Try again*) instead of breaking the page; a crash leaves
a log in `~/.local/state/charted/` and the next start offers a prefilled GitHub issue
(nothing is sent unless you send it). Release numbers are in `docs/perf.md`.
